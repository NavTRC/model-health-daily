# 模型健康日報（課堂練習）

產線上有好幾支辨識模型，辨識率掉了常常要等客訴或停線才發現。
這個工具每天看一次模型運作紀錄，**只把要人決定的模型挑出來**；要不要重訓、回滾或停用，由人決定。

> 課堂練習作品（智動協會《製造業 AI Agent 實務應用》D4）。資料是**虛擬練習資料**（嶺碩自動化，虛構），不是實際產線數據。

## 頁面

| 路徑 | 用途 |
|---|---|
| `/` | 日報看板（手機優先），第一行是結論 |
| `/slides.html` | 簡報：怎麼用、怎麼回報問題（可下載） |
| `/report.html` | 回報問題 |
| `/admin` | 負責人看回報、改處理狀態（需管理密碼） |

## 狀態規則

- **異常**：今天辨識率 < 95%，或比昨天掉超過 3 個百分點
- **警示（漂移）**：連續 3 天下降且累計掉超過 2 點
- **資料異常**：今天筆數 < 前 7 天平均的 50%
- 規則在 `public/health.js`，網頁與後端共用

## 部署

GitHub → Cloudflare Workers（自動部署）。
- Workers AI（`AI` 綁定）：寫摘要，不用金鑰；失敗時改用規則文字
- KV（`REPORTS` 綁定）：存回報
- 機密設定 `ADMIN_KEY`：管理頁密碼（在 Cloudflare 設定，不放在程式裡）
